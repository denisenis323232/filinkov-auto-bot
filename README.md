# FILINKOV AUTO bot

Telegram-контент-менеджер для FILINKOV AUTO.

## Что уже заложено
- приём `.xls/.xlsx` в Telegram;
- разбор файла поставщика;
- фильтр автомобилей 3–5 лет и `<=160 л.с.`;
- SQLite-база и защита от дублей;
- очередь модерации;
- получение фото/видео с карточки поставщика;
- курс CNY/RUB ЦБ РФ;
- формула: `цена авто + 13 000 CNY + таможня + 200 000 ₽ + 140 000 ₽`;
- ручной ввод таможни до подключения ТКС API;
- генерация текста поста;
- подсказка для голосового и сохранение реального voice message;
- approve / skip / edit / publish now;
- публикация альбома, текста, видео и voice в Telegram-канал;
- расписание 12:00 и 18:00 при `AUTO_PUBLISH=true`.

## Безопасность
Токен, который когда-либо был отправлен в чат, нужно отозвать в BotFather и создать новый. Новый токен хранится только в секретной переменной `TELEGRAM_BOT_TOKEN` на хостинге и не коммитится в GitHub.

## Локальный запуск
```bash
pip install -r requirements.txt
export TELEGRAM_BOT_TOKEN='...'
python run.py
```

## Первый запуск
1. Владелец первым пишет боту `/start` — его Telegram ID фиксируется как администратор.
2. `/setchannel @filinkovauto`
3. Добавить бота администратором канала с правом публикации.
4. Отправить Excel.
5. Открыть очередь, проверить автомобиль, нажать `📸 Получить фото`, ввести таможню и сделать тестовую публикацию.

## Деплой
Проект подготовлен под Railway (`Dockerfile` + `railway.toml`). Для SQLite на Railway нужен постоянный Volume и `DATA_DIR` на путь этого Volume.

## Следующий этап
После первого запуска на Railway подстраиваем `app/source_avtomir.py` под реальную HTML-структуру `avtomirhrb.ru`, если универсальный сборщик не поймает галерею. Затем подключаем ТКС API и автоматическую замену брендинга на фотографиях.
